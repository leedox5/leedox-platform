# 🚀 Antigravity 개발 실전: 15년 차 베테랑의 AI 에이전트 무중력 코딩 (`aigravity`)

> **"AI 챗봇에게 코드 작성을 '구걸'하지 마라. 전담 수석 에이전트로 길들여 무중력 개발(Zero-Gravity Dev)을 경험하라!"**

---

## 📌 클래스 소개 (Course Overview)

본 코스는 15년 이상 Java/Spring 및 데이터베이스 백엔드 실무를 총괄해 온 **베테랑 개발자 토미(Tommy)**와 Google DeepMind가 만든 자율형 코딩 에이전트 **Antigravity(안티그래비티)**가 실제로 함께 나누는 대화, 설치 과정, 세션 캡처, 그리고 레거시 시스템 고도화 프로세스를 100% 라이브로 기록한 **실무형 에이전트 마스터 클래스**입니다.
